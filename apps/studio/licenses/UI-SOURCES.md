# UI source provenance

The customer control plane uses the official Untitled UI React library (version 8), installed on 2026-10-18 using the authenticated Untitled UI MCP and the CLI command it returned:

```sh
npx untitledui@latest add button input select checkbox table modal --yes
```

The CLI installs the six component groups and their supporting components. Studio maps icon imports to licensed Font Awesome Pro Regular, namespaces semantic color utilities, and preserves native-select accessible labels when no visible label is passed. Library interaction behavior is retained.

Nexbic supplies the authorized reference theme, typography, local Geist Variable font and Font Awesome Pro Regular 7.3.1 icon definitions. Only selected icon definitions are bundled. Access and registry tokens are not part of these sources. Retain the accompanying license notices.

AI components: complete Stack Proc review

201 components · 31 groups · 20 October 2026

Direction: a fullscreen activity workspace whose main surface hosts the work product. Plans, decisions, execution evidence and instructions are contextual supporting surfaces. Agent definitions, activities, runs, artifacts and decisions retain distinct identities.

Coverage: every catalog entry classified; 194 public detail descriptions inspected. Seven detail pages were unavailable. Interactive behavior and premium source have not been comprehensively audited; most first-load preview captures were still loading. No components installed and no application layout changed.

Integration: preserve Untitled UI, Font Awesome, existing workflow/ontology editors, MiniMax and the durable Stack Proc runtime. Borrow composition and interaction patterns through adapters. A UI component never implies execution, permissions, recovery, streaming, collaboration or evaluation support.

Proposed order: fullscreen shell and activity identity → artifact/decision hosts → actual execution events and recovery → editor assistance and typed tool results → ambient overview and notifications → additional administration and domain renderers.

Unavailable detail pages: Instructions editor; Source ingest; Retrieval inspector; Agent plan; Cursor-style questions panel; Workspace switcher; Profile settings. Their catalog descriptions inform provisional assessments. Agent plan's public description was also inspected during the earlier reference pass.
